# Funngro Website Revamp Prototype

Open `index.html` to view the Teen page.
Open `company.html` to view the Company page.

## Local preview
Any static server can serve this folder. For example:
`python -m http.server 8000`

Then open:
`http://localhost:8000`

## Deployment
Upload the folder to a static hosting service such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

Before submission:
- replace canonical URLs with the deployed URL
- verify all brand claims/content
- run Lighthouse
- test on Android and desktop
- submit the public website URL in the Funngro project remark
